PROLOGUE

시작 · 임계 z값 정의

Critical z-values
단측 임계값 \(z_\alpha\)

수학적 정의: \(P(Z > z_\alpha) = \alpha\). 따라서 \(P(Z \le z_\alpha) = 1 - \alpha\).

양수 \(z_\alpha\)보다 양의 방향으로 더 멀리 떨어진 \(Z\)들이 가지는 확률이 정확히 \(\alpha\)인 경계점. 단측 가설 검정의 기준점이라 critical value라 부릅니다.

양측 임계값 \(z_{\alpha/2}\)

수학적 정의: \(P(Z > z_{\alpha/2}) = \alpha/2\). 따라서 \(P(-z_{\alpha/2} \le Z \le z_{\alpha/2}) = 1 - \alpha\).

유의수준 \(\alpha\)에서 양쪽 꼬리 합이 \(\alpha\)가 되는 경계점. 신뢰도 \(1 - \alpha\) 신뢰구간과 양측 가설 검정의 기준점.

\(\alpha\)\(1 - \alpha\)\(z_\alpha\)\(z_{\alpha/2}\)
0.1090%1.281.65
0.0595%1.651.96
0.0199%2.332.58
QUESTION 01 — Proportion CI & H.T.

Q1. kaistshop 구매 확률 p 추정

n=900, 구매 27 / 비율 CI · 양측·단측 H.T. · CI vs H.T. SE 함정
문제

고객이 kaistshop.com을 방문할 때마다 구매로 이어질 확률을 \(p\)라 한다. 900회 무작위 방문 표본 중 27번이 구매로 이어졌다.

(a) \(p\)의 95% 신뢰구간을 구하시오.

(b) \(\alpha = 5\%\)에서 \(p \ne 2\%\) 를 뒷받침할 통계적 증거가 되는가?

(c) \(\alpha = 5\%\)에서 \(p > 2\%\) 를 뒷받침할 통계적 증거가 되는가?

(a) 95% 신뢰구간

① 표본평균: \(\bar{p} = \dfrac{27}{900} = 0.03 = 3\%\)

② 표준오차 (표본 평균의 표준편차):

\[ \sigma_{\bar{p}} = \sqrt{\frac{p(1-p)}{n}} \simeq \sqrt{\frac{\bar{p}(1-\bar{p})}{n}} = \sqrt{\frac{0.03 \times 0.97}{900}} = 0.0057 = 0.57\% \]

③ 신뢰구간:

\[ \left(\bar{p} - z_{\alpha/2}\sqrt{\frac{\bar{p}(1-\bar{p})}{n}},\ \bar{p} + z_{\alpha/2}\sqrt{\frac{\bar{p}(1-\bar{p})}{n}}\right) \]
\[ = (0.03 - 1.96 \times 0.0057,\ 0.03 + 1.96 \times 0.0057) = (0.019,\ 0.041) = (1.9\%,\ 4.1\%) \]
(a) 답

95% 신뢰구간 \(\approx (1.9\%, 4.1\%)\). 진짜 구매 비율이 약 95% 확률로 이 사이에 있음.

(b) 양측 검정 · p ≠ 2%

① 가설: \(H_0 : p = 2\%, \quad H_1 : p \ne 2\%\)

② z-통계량 (H₀ 하에서 표준 거리):

\[ z = \frac{\bar{p} - p}{\sqrt{p(1-p)/n}} = \frac{0.03 - 0.02}{\sqrt{0.02 \times 0.98 / 900}} = \frac{0.01}{0.00467} = 2.14 \]

③ p-값 (양측): \(p\text{-value} = 2 \cdot P(Z > 2.14) = 2 \times 0.0162 = 0.0324\)

④ 결론: \(0.0324 < 0.05 = \alpha\) → \(H_0\) 기각.

임계값 비교로도 같은 결론: \(1.65 < 1.96 < 2.14 < 2.58\). 즉, 5%·10% 수준에서는 기각, 1% 수준에서는 기각 못 함.

(b) 답

5% 유의수준에서 \(p \ne 2\%\) 라는 증거가 통계적으로 충분함 — 진짜 구매 비율이 2%가 아니라고 결론 가능.

[주의!] CI 결과와 H.T. 결과의 불일치

2%는 (a)의 95% CI \((1.9\%, 4.1\%)\) 안에 들어가는데, (b)의 H.T.는 기각한다고 결론냈죠. 모순이에요.

원인: CI의 SE는 \(\bar{p} = 3\%\) 기반 근사 (진짜 \(p\)를 모르니까), 반면 H.T.의 SE는 \(H_0\)의 \(p = 2\%\) 기반 정확치. 두 SE가 다르기 때문에 결론도 갈릴 수 있습니다.

이번처럼 결론이 갈리면 H.T. 결과(기각)가 옳습니다 — H.T.가 \(H_0\) 하에서 정확한 SE를 쓰니까.

(c) 단측 검정 · p > 2%

① 가설: \(H_0 : p \le 2\%, \quad H_1 : p > 2\%\)

② z-값: 같음. \(z = 2.14\)

③ p-값 (단측): \(p\text{-value} = P(Z > 2.14) = 0.0162 < 0.05 = \alpha\)

④ 결론: \(H_0\) 기각, \(H_1\) 채택.

또는 임계값으로: \(2.14 > 1.65\) 이므로 5% 유의수준에서 기각.

(c) 답

5%에서 \(p > 2\%\) 라는 통계적 증거가 충분함.

QUESTION 02 — Mean CI (3 levels)

Q2. 우리은행 ATM 평균 인출액

n=50, X̄=45,000, σ=12,000 / 90·95·99% CI + 양측·단측 H.T.
문제

KAIST 캠퍼스 ATM의 50명 고객 표본 평균이 45,000원, 모표준편차 \(\sigma = 12{,}000\)원으로 알려져 있다.

(a) 평균의 표준오차는?

(b) 90%, 95%, 99% 신뢰구간을 구하시오.

(c) 작년 평균 42,000원이 아니라는 증거를 \(\alpha = 1\%, 5\%, 10\%\)에서 검정.

(d) 평균이 42,000보다 크다는 증거를 \(\alpha = 1\%, 5\%, 10\%\)에서 검정 (경영지원팀 권고).

(a) 평균의 표준오차

\[ \sigma_{\bar{X}} = \frac{\sigma}{\sqrt{n}} = \frac{12{,}000}{\sqrt{50}} = 1{,}700 \]
(a) 답

\(\sigma_{\bar{X}} = 1{,}700\)원

(b) 신뢰구간 3종

공식: \(\left(\bar{X} - z_{\alpha/2}\sigma_{\bar{X}},\ \bar{X} + z_{\alpha/2}\sigma_{\bar{X}}\right)\)

신뢰수준\(z_{\alpha/2}\)MECI
90%1.652,805(42,195, 47,805)
95%1.963,332(41,668, 48,332)

(c) 양측 검정 · μ ≠ 42,000

① 가설: \(H_0 : \mu = 42{,}000, \quad H_1 : \mu \ne 42{,}000\)

② z-통계량:

\[ z = \frac{\bar{X} - \mu}{\sigma_{\bar{X}}} = \frac{45{,}000 - 42{,}000}{1{,}700} = 1.76 \]

③ p-값 (양측): \(p\text{-value} = 0.0392 \times 2 = 0.0784 = 7.84\%\)

① 가설: \(H_0 : \mu \le 42{,}000, \quad H_1 : \mu > 42{,}000\)

② z-값: 경계상황 \(\mu = 42{,}000\)에서 \(z = 1.76\) (같음).

③ p-값 (단측): \(p\text{-value} = 0.0392 = 3.92\%\) (양측의 절반)

5%, 10%에서 평균 인출액이 42,000원보다 크다는 증거 충분. → 준비 금액 증가 고려 권고. 단, 1%에선 결정 보류.

QUESTION 03 — Three methods for H.T.

Q3. GS25 생수 일일 평균 수요

n=100, Σ=150,000, σ=397 / p-value · z-value · CI 세 방법
문제

GS25 매장 100일간 생수 판매량 합계 150,000병, 모표준편차 \(\sigma = 397\)병/일.

(a) 표본평균과 표준오차.

(b) 90·95·99% CI.

(c) \(\mu = 1{,}425\) 인지 \(\alpha = 1\%, 5\%, 10\%\)에서 (i) p-값 (ii) z-값 (iii) CI 세 방법으로 검정.

(d) CI로만 \(\mu = 1{,}580\) 검정. p-값에 대해 어떤 결론?

(a) 표본평균과 표준오차

\[ \bar{X} = \frac{\sum X_i}{n} = \frac{150{,}000}{100} = 1{,}500 \]
\[ \sigma_{\bar{X}} = \frac{\sigma}{\sqrt{n}} = \frac{397}{\sqrt{100}} = 39.7 \quad \text{(근사 아닌 정확치)} \]

(b) 신뢰구간 3종

신뢰수준\(z_{\alpha/2}\)MECI
90%1.6565.5(1,434.5, 1,565.5)
95%1.9677.8(1,422.2, 1,577.8)
99%2.58102.4(1,397.6, 1,602.4)

(c) μ = 1,425 검정 — 세 방법

① 가설: \(H_0 : \mu = 1{,}425, \quad H_1 : \mu \ne 1{,}425\)

② z-통계량:

\[ z = \frac{1{,}500 - 1{,}425}{39.7} = 1.89 \]

방법 i) p-값: \(P(Z > 1.89) \times 2 = 0.029 \times 2 = 0.058 = 5.8\%\)

→ 10%에서 \(H_0\) 기각, 5%·1%에서 기각 못 함.

방법 ii) z-값 비교: 임계 z = 2.58, 1.96, 1.65. \(z = 1.89\) 이므로 1.65 보다 큼 → 10%에서 기각, 1.96·2.58 못 넘음 → 5%·1% 못 함.

방법 iii) CI: 90% CI 만 1,425가 안 들어감 → 10%에서 기각. 95%·99% CI에는 들어감 → 5%·1% 못 함.

(c) 답 — 세 방법 모두 같은 결론

10% 유의수준에서 \(H_0\) 기각, 5%·1%에서 기각 못 함. 세 방법의 결론이 일치하는 것이 검정의 일관성.

(d) CI로만 μ = 1,580 검정

1,580이 어느 CI에 들어가는지:

  • 90% CI: (1,434.5, 1,565.5) — 1,580 안 들어감 → 10% 기각
  • 95% CI: (1,422.2, 1,577.8) — 1,580 안 들어감 → 5% 기각
  • 99% CI: (1,397.6, 1,602.4) — 1,580 들어감 → 1% 기각 못 함

p-값에 대한 추론: 5%에서 기각, 1%에서 기각 못 함 → \(0.01 < p\text{-value} < 0.05\).

(d) 답

5%·10%에서 기각, 1%에서 기각 못 함. p-값은 1%보다 크고 5%보다 작은 사이에 위치.

QUESTION 04 — Proportions: one and two

Q4. 한식/양식 메뉴 선호 (서울·대전)

n_S=850, 양식 365 / n_D=620, 양식 237 — 한 비율 + 두 비율
문제

서울 캠퍼스 850명 중 485명이 한식, 365명이 양식 선호. 대전 캠퍼스 620명 중 237명이 양식 선호.

(a) 양식 선호 비율의 CI 3종 (서울).

(b) 서울 양식 비율 ≠ 40% 검정 (\(\alpha = 5\%\)).

(c) 서울 양식 비율 > 40% 검정 (\(\alpha = 5\%\)).

(d) 두 집단 비율 비교 — 한눈에 충분히 다른가?

(e) 두 비율 차이의 CI 3종.

(f) \(p_S \ne p_D\) 검정 (\(\alpha = 5\%\)).

(g) \(p_S > p_D\) 검정 (\(\alpha = 5\%\)).

0단계 · 기호 정리

서울: \(n_S = 850\), 양식 365 → \(\hat{p}_S = 365/850 = 0.429 = 42.9\%\)
대전: \(n_D = 620\), 양식 237 → \(\hat{p}_D = 237/620 = 0.382 = 38.2\%\)

(a) 서울 양식 선호 비율 CI

표준오차:

\[ \text{SE} = \sqrt{\frac{0.429 \times (1 - 0.429)}{850}} = 0.017 \]
신뢰수준\(z_{\alpha/2}\)CI
90%1.65(40.1%, 45.7%)
95%1.96(39.6%, 46.2%)
99%2.58(38.5%, 47.3%)

(b) 양측 검정 · p_S ≠ 40%

① 가설: \(H_0 : p_S = 40\%, \quad H_1 : p_S \ne 40\%\)

② z-통계량 (H₀ 하):

\[ z = \frac{0.429 - 0.40}{\sqrt{0.4 \times 0.6 / 850}} = 1.73 \]

③ p-값 (양측): \(0.0418 \times 2 = 0.0836 > 5\%\)

④ 결론: 5%에서 \(H_0\) 기각 못 함.

(c) 단측 검정 · p_S > 40%

같은 \(z = 1.73\). 단측 p-값 \(= 0.0418 < 5\%\) → \(H_0\) 기각.

(b)와 (c)의 차이

같은 데이터·같은 z. 양측에서는 기각 못 했지만 단측에서는 기각. 방향을 미리 정해두면 같은 신호가 두 배 강한 증거로 인정되는 것 — 그래서 단측은 사전에 방향이 정해진 경우에만 사용.

(d) 두 집단 한눈 비교

\(\hat{p}_S - \hat{p}_D = 0.429 - 0.382 = 4.7\%p\). 언뜻 보면 다른 집단으로 볼 만큼 차이가 있어 보임. (e)~(g)에서 통계로 검증.

(e) 두 비율 차이의 CI

표준오차 (분리 추정):

\[ \text{SE} = \sqrt{\frac{\hat{p}_S(1-\hat{p}_S)}{n_S} + \frac{\hat{p}_D(1-\hat{p}_D)}{n_D}} = \sqrt{\frac{0.429 \times 0.571}{850} + \frac{0.382 \times 0.618}{620}} = 2.59\% \]
신뢰수준\(z_{\alpha/2}\)CI0 포함?
90%1.65(0.43%, 8.97%)안 들어감
95%1.96(−0.37%, 9.77%)들어감
99%2.58(−1.97%, 11.37%)들어감

10%에서만 두 비율이 다르다는 신호. 5%·1%에서는 증거 부족.

(f) 양측 검정 · p_S ≠ p_D

① 가설: \(H_0 : p_S = p_D, \quad H_1 : p_S \ne p_D\)

② Pooled 표준오차 (H₀ 하):

\(H_0\)가 참이면 \(p_S = p_D = p\)이므로 두 집단을 합쳐 \(p\)를 추정:

\[ \bar{p} = \frac{365 + 237}{850 + 620} = \frac{602}{1{,}470} = 0.4095 \]
\[ \text{SE} \simeq \sqrt{\frac{\bar{p}(1-\bar{p})}{n_S} + \frac{\bar{p}(1-\bar{p})}{n_D}} = \sqrt{\frac{0.4095 \times 0.5905}{850} + \frac{0.4095 \times 0.5905}{620}} = 0.0260 \]

③ z-통계량:

\[ z = \frac{\hat{p}_S - \hat{p}_D}{\text{SE}} = \frac{0.0472}{0.0260} = 1.816 < 1.96 \]

④ p-값 (양측): \(0.0347 \times 2 = 0.0694 = 6.94\% > 5\%\)

⑤ 결론: 5%에서 \(H_0\) 기각 못 함.

(g) 단측 검정 · p_S > p_D

같은 \(z = 1.816\). \(1.816 > 1.65\) (단측 임계값) 이므로 5%에서 \(H_0\) 기각.

p-값: \(0.0347 < 5\%\) → 같은 결론.

Q4 정리

두 비율 비교에서 CI는 분리 추정, H.T.는 pooled \(\bar{p}\). 양측과 단측의 결론이 다르게 나올 수 있음에 유의.

QUESTION 05 — Two independent means

Q5. CK푸드 KAIST vs B대학 월 식비

n_x=n_y=500 / 독립 표본 — 두 평균 차이
문제

KAIST 식당: \(\bar{X} = 255{,}200\)원, \(\sigma_x = 78{,}500\)원. B대학: \(\bar{Y} = 242{,}800\)원, \(\sigma_y = 94{,}700\)원. 각각 \(n = 500\), 독립.

(a) \(\mu_x - \mu_y\)의 90·95·99% CI.

(b) \(\mu_x - \mu_y \ne 0\) 검정 (1%).

(c) \(\mu_x - \mu_y > 0\) 검정 (1%).

(a) 두 평균 차이의 CI

① 표본 평균 차이: \(\bar{X} - \bar{Y} = 12{,}400\)원

② 표준오차:

\[ \sigma_{\bar{X} - \bar{Y}} = \sqrt{\frac{\sigma_x^2}{n_x} + \frac{\sigma_y^2}{n_y}} = \sqrt{\frac{78{,}500^2}{500} + \frac{94{,}700^2}{500}} = 5{,}501 \]
신뢰수준\(z_{\alpha/2}\)CI
90%1.65(3,323, 21,477)
95%1.96(1,618, 23,182)
99%2.58(−1,793, 26,593)

(b) 양측 검정 · μ_x − μ_y ≠ 0

① 가설: \(H_0 : \mu_x - \mu_y = 0, \quad H_1 : \mu_x - \mu_y \ne 0\)

② z-통계량:

\[ z = \frac{\bar{X} - \bar{Y}}{\sigma_{\bar{X}-\bar{Y}}} = \frac{255{,}200 - 242{,}800}{5{,}501} = 2.25 \]

③ 비교: \(2.25 < 2.58 = z_{0.005}\). p-값 \(= P(Z > 2.25) \times 2 = 0.012 \times 2 = 2.4\% > 1\%\).

④ 결론: 1%에서 \(H_0\) 기각 못 함.

(c) 단측 검정 · μ_x − μ_y > 0

같은 \(z = 2.25 < 2.33 = z_{0.01}\). 단측 p-값 \(= 1.2\% > 1\%\) → 1%에서 기각 못 함.

Q5 정리

두 독립 평균 차이는 SE에 \(\sqrt{\sigma_x^2/n_x + \sigma_y^2/n_y}\). 같은 z=2.25라도 \(\alpha\) 기준이 엄격하면 기각 못 함 — 5%였다면 양측·단측 모두 기각이었을 것.

QUESTION 06 — Paired sample

Q6. 본관 vs 기타 학생식당 (짝 표본)

n=500, D=X−Y / 짝지은 표본 — S_D 사용
문제

같은 학생 500명에게 본관 식당(X)과 기타 식당(Y) 월 식비를 각각 조사.

표본 평균: \(\bar{X} = 298{,}100\)원, \(\bar{Y} = 289{,}200\)원.

표본 표준편차: \(S_X = 63{,}100\)원, \(S_Y = 49{,}400\)원.

차이 \(D = X - Y\)의 표본 표준편차 \(S_D = 88{,}700\)원.

(a) \(\mu_x - \mu_y \ne 0\) 검정 (\(\alpha = 1\%\)).

(b) \(\mu_x - \mu_y < 0\) 검정 (\(\alpha = 1\%\)).

핵심 · 짝 표본의 특수성

왜 독립 공식 못 씀?

같은 사람에서 \(X\)와 \(Y\)를 둘 다 측정 — 두 측정값이 서로 상관됨. 그래서 \(\text{Var}[\bar{X} - \bar{Y}]\)에 공분산 항이 들어가야 함.

해결: \(D = X - Y\)를 새 변수로 만들면 한 표본 문제로 환원. \(S_D\)는 데이터에서 직접 측정 (\(S_X, S_Y\)로 계산 불가).

(a) 양측 검정 · μ_x − μ_y ≠ 0

① 가설: \(H_0 : \mu_x - \mu_y = 0, \quad H_1 : \mu_x - \mu_y \ne 0\)

② \(\bar{D}\) 계산: \(\bar{D} = \bar{X} - \bar{Y} = 298{,}100 - 289{,}200 = 8{,}900\)

③ 표준오차 (\(\sigma_D\) 모르니 \(S_D\)로 근사):

\[ \text{SE}_{\bar{D}} \simeq \frac{S_D}{\sqrt{n}} = \frac{88{,}700}{\sqrt{500}} = \frac{88{,}700}{22.36} = 3{,}966 \]

④ z-통계량:

\[ z = \frac{\bar{D} - 0}{S_D / \sqrt{n}} = \frac{8{,}900}{3{,}966} = 2.24 \]

⑤ p-값 (양측): \(p\text{-value} = 2 \cdot P(Z > 2.24) = 2.49\% > 1\%\)

⑥ 결론: 1%에서 \(H_0\) 기각 못 함.

(b) 단측 검정 · μ_x − μ_y < 0

① 가설: \(H_0 : \mu_x - \mu_y \ge 0, \quad H_1 : \mu_x - \mu_y < 0\)

② 관찰값 검토: \(\bar{X} - \bar{Y} = 8{,}900 \ge 0\) — 이미 \(H_0\)에 부합!

관찰된 표본 자체가 "본관이 기타보다 큼" 방향이므로, \(H_1\)("본관 < 기타") 을 뒷받침할 증거가 처음부터 없음. p-값을 계산할 필요조차 없이 결론 가능.

③ 결론: 어떤 유의수준에서도 \(H_0\) 기각 못 함.

Q6 정리

짝 표본: \(D = X - Y\)로 변환 후 한 표본 검정. SE에 \(S_D / \sqrt{n}\). 그리고 단측 검정에서는 관측 방향이 \(H_1\)과 반대면 계산 없이 기각 못 함을 알 수 있음.

KEY TAKEAWAY
Q1~Q6 풀이의 흐름은 모두 같음 — ① 가설 설정 → ② 표준오차 계산 → ③ z-통계량 → ④ p-값 (또는 임계값 비교) → ⑤ 결론. 차이는 SE 공식 (한 비율 vs 두 비율, 독립 vs 짝, σ 알려짐 vs 추정) 뿐. 시험장에선 SE만 정확히 골라쓰면 절반 완성.
