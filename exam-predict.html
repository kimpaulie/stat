시험 예상 문제 12유형 — 정규분포부터 회귀까지 한 번에

Lecture 5~10에서 다룬 모든 핵심 유형을 12개 예상 문제로 압축했습니다. 각 문제는 시험에서 자주 나오는 패턴을 대표하고, 풀이는 ① 가설/식 → ② SE/표준화 → ③ p-값/CI → ④ 결론 4단계로 통일.

이 12문제를 손으로 풀 수 있으면 기말 문제의 80%는 같은 틀로 풀립니다.

출제 빈도 표시

각 문제 헤더에 🔥(매년 출제) / ⭐(자주 출제) / ✏️(가끔 출제) 로 표시했어요.

PROBLEM 01 · 정규분포 표준화

① 다운로드 시간 — 확률 계산 🔥

X ~ N(8, 2²) / 시간 임계 확률
문제

MyTVLab 영화 한 편의 다운로드 시간 \(X\)는 평균 8분, 표준편차 2분인 정규분포를 따른다.

(a) 다운로드가 10분 이상 걸릴 확률은?

(b) 다운로드가 5분 미만으로 끝날 확률은?

(c) 다운로드가 6~9분 사이일 확률은?

풀이

표준화: \(Z = \dfrac{X - \mu}{\sigma} = \dfrac{X - 8}{2}\) ~ \(N(0, 1)\).

(a) \(X = 10\) → \(z = (10-8)/2 = 1.0\). \(P(X > 10) = P(Z > 1.0) = 1 - 0.8413 = \mathbf{0.1587}\) (15.87%)

(b) \(X = 5\) → \(z = (5-8)/2 = -1.5\). \(P(X < 5) = P(Z < -1.5) = 1 - 0.9332 = \mathbf{0.0668}\) (6.68%)

(c) \(X = 6\) → \(z_1 = -1.0\), \(X = 9\) → \(z_2 = 0.5\).

\(P(6 \le X \le 9) = P(-1 \le Z \le 0.5) = 0.6915 - (1 - 0.8413) = 0.6915 - 0.1587 = \mathbf{0.5328}\) (53.28%)

정답

(a) 15.87% / (b) 6.68% / (c) 53.28%

핵심 패턴

Z-표는 왼쪽 꼬리 확률 \(P(Z \le z)\)를 줌. 음수 \(z\)는 대칭성 \(P(Z \le -z) = 1 - P(Z \le z)\)로 변환.

PROBLEM 02 · 정규분포 역방향

② 호텔 객실 — 임계값 찾기 ⭐

상위 N% 컷오프 / Z⁻¹
문제

한 호텔 체인의 일일 객실 예약 수 \(X\) ~ \(N(\mu = 200, \sigma^2 = 30^2)\).

(a) 예약이 상위 5%인 "고객수일"은 몇 건 이상인가?

(b) 매니저가 "하루 예약 90%를 처리할 객실"을 미리 준비하려면 객실을 몇 개로 잡아야 하나?

풀이

(a) \(P(X > k) = 0.05\) → \(P(Z > z) = 0.05\) → \(z = 1.65\) (단측 임계값).

\(z = (k - 200)/30 = 1.65\) → \(k = 200 + 1.65 \times 30 = 249.5\). 249.5건 이상이면 상위 5%에 해당.

(b) 매니저는 "예약을 처리할 객실"이 부족할 확률을 10% 이하로 → \(P(X \le k) = 0.90\) → \(z = 1.28\).

\(k = 200 + 1.28 \times 30 = 238.4\) → 239개 객실 준비.

정답

(a) 249.5건 이상 / (b) 239개

핵심 패턴

"확률 → 임계값" 문제는 임계 z값 표 (1.28 / 1.65 / 1.96 / 2.33 / 2.58) 외워두면 즉시 해결. 식: \(k = \mu + z \cdot \sigma\).

PROBLEM 03 · CLT 응용

③ 카페 음료 분량 — 표본평균의 분포 🔥

CLT — X̄ ~ N(μ, σ²/n)
문제

한 카페가 판매하는 라떼 한 잔의 분량 \(X\)는 평균 250ml, 표준편차 15ml로 알려져 있다. 분포 모양은 모른다.

(a) 한 잔이 240ml 미만일 확률은? (계산 가능?)

(b) 무작위 36잔의 평균 분량이 245ml 미만일 확률은?

(c) 무작위 100잔의 평균 분량이 248~252ml 사이일 확률은?

풀이

(a) 한 잔 \(X\)의 분포 모양을 모르므로 정규분포 가정 불가 → 계산 불가 (혹은 분포 가정 명시 필요).

(b) CLT: \(n = 36 \ge 30\)이므로 \(\bar{X} \sim N(250, 15^2/36) = N(250, 6.25)\), 표준편차 \(15/\sqrt{36} = 2.5\).

\(z = (245 - 250)/2.5 = -2\). \(P(\bar{X} < 245) = P(Z < -2) = 1 - 0.9772 = \mathbf{0.0228}\) (2.28%)

(c) \(n = 100\), SE \(= 15/\sqrt{100} = 1.5\). \(z_1 = (248-250)/1.5 = -1.33\), \(z_2 = (252-250)/1.5 = 1.33\).

\(P(248 \le \bar{X} \le 252) = P(-1.33 \le Z \le 1.33) = 0.9082 - 0.0918 = \mathbf{0.8164}\) (81.64%)

정답

(a) 계산 불가 / (b) 2.28% / (c) 81.64%

⚠️ 함정

(a)는 "한 잔"의 확률 — CLT 적용 X. CLT는 표본평균(여러 잔의 평균)의 분포를 알려주는 정리. 단일 관측치에는 적용 안 됨.

PROBLEM 04 · CLT 비율

④ 광고 클릭률 — 표본비율의 분포 ⭐

p̂ ~ N(p, p(1-p)/n)
문제

광고 한 번 노출 시 클릭으로 이어질 확률 \(p = 0.10\). 광고를 \(n = 400\)명에게 노출했다.

(a) 표본비율 \(\hat{p}\)의 평균과 표준오차는?

(b) 표본비율 \(\hat{p}\)이 12% 이상일 확률은?

(c) 표본비율 \(\hat{p}\)이 8%~12% 사이일 확률은?

풀이

(a) \(E[\hat{p}] = p = 0.10\). SE \(= \sqrt{p(1-p)/n} = \sqrt{0.10 \times 0.90 / 400} = \sqrt{0.000225} = 0.015\).

CLT: \(np = 40 \ge 5\) and \(n(1-p) = 360 \ge 5\) → \(\hat{p} \sim N(0.10, 0.015^2)\) 근사.

(b) \(z = (0.12 - 0.10)/0.015 = 1.33\). \(P(\hat{p} > 0.12) = P(Z > 1.33) = 1 - 0.9082 = \mathbf{0.0918}\) (9.18%)

(c) \(z_1 = -1.33\), \(z_2 = 1.33\) (대칭). \(P(0.08 \le \hat{p} \le 0.12) = 2 \times 0.9082 - 1 = \mathbf{0.8164}\) (81.64%)

정답

(a) 평균 0.10, SE 0.015 / (b) 9.18% / (c) 81.64%

핵심 패턴

표본비율의 CLT 조건: \(np \ge 5\) 그리고 \(n(1-p) \ge 5\). 둘 다 만족하면 정규 근사 가능.

PROBLEM 05 · 한 평균 CI

⑤ 배달 시간 신뢰구간 🔥

σ 알려진 경우 — z-CI
문제

배달 앱 사용자 100명의 평균 배달 시간이 32분으로 측정됨. 모표준편차 \(\sigma = 8\)분.

(a) 95% 신뢰구간을 구하시오.

(b) 99% 신뢰구간을 구하시오.

(c) 90% 신뢰구간을 구하시오.

(d) 신뢰수준이 높을수록 구간이 어떻게 변하는가? 이유는?

풀이

SE \(= \sigma/\sqrt{n} = 8/\sqrt{100} = 0.8\). 식: \(\bar{X} \pm z_{\alpha/2} \cdot \text{SE}\).

신뢰수준\(z_{\alpha/2}\)MECI
(c) 90%1.651.32(30.68, 33.32)
(a) 95%1.961.568(30.43, 33.57)
(b) 99%2.582.064(29.94, 34.06)

(d) 신뢰수준이 높을수록 구간이 넓어진다. 이유: 더 많은 모평균 값을 "포함 가능"으로 받아들이려면 구간이 커져야 함. 99% CI는 1% 위험만 감수하므로 90% CI(10% 위험)보다 훨씬 큼.

정답

(a) 95% CI = (30.43, 33.57) / (b) 99% CI = (29.94, 34.06) / (c) 90% CI = (30.68, 33.32)

PROBLEM 06 · 한 비율 CI

⑥ 만족도 조사 — 비율 신뢰구간 ⭐

p̂ ± z·√[p̂(1-p̂)/n]
문제

500명 고객을 대상으로 한 만족도 조사에서 320명이 "만족"이라 답했다.

(a) 만족 비율의 95% 신뢰구간을 구하시오.

(b) "전체 고객의 65%가 만족한다"는 주장은 통계적으로 지지되는가? (CI 기반 판단)

(c) 신뢰구간의 폭을 절반으로 줄이려면 표본을 몇 배로 늘려야 하나?

풀이

\(\hat{p} = 320/500 = 0.64\). SE \(= \sqrt{\hat{p}(1-\hat{p})/n} = \sqrt{0.64 \times 0.36 / 500} = \sqrt{0.000461} = 0.0215\).

(a) 95% CI: \(0.64 \pm 1.96 \times 0.0215 = (0.598, 0.682)\). 즉 (59.8%, 68.2%).

(b) 0.65는 95% CI \((0.598, 0.682)\) 안에 있음 → "만족 비율 = 65%" 주장을 5% 유의수준에서 기각할 수 없음. 65%일 가능성을 지지함.

(c) CI 폭은 \(2 \cdot z \cdot \sigma/\sqrt{n}\)에 비례. 폭을 절반으로 → \(\sqrt{n}\)을 2배로 → \(n\)을 4배로 (= 2,000명).

정답

(a) (59.8%, 68.2%) / (b) 기각 못 함 — 65%가 CI에 포함됨 / (c) 4배 (2,000명)

핵심 패턴

CI 폭 ↓ 4배 룰 — 정밀도를 2배로 올리려면 표본을 4배. SE에 \(\sqrt{n}\)이 들어가서 그렇습니다.

PROBLEM 07 · 한 평균 H.T. 양측

⑦ 신제품 무게 검정 🔥

양측 검정 — μ ≠ 표시값
문제

한 과자 봉지에 "내용량 200g"으로 표시되어 있다. 품질 관리팀이 무작위 64봉지의 무게를 잰 결과 표본평균 \(\bar{X} = 197.5\)g. 모표준편차 \(\sigma = 8\)g으로 알려져 있다.

표시된 200g과 실제 평균이 다른지 \(\alpha = 5\%\)에서 검정하시오.

풀이

① 가설: \(H_0 : \mu = 200, \quad H_1 : \mu \ne 200\) (양측).

② SE: \(\sigma/\sqrt{n} = 8/\sqrt{64} = 1\).

③ z-통계량: \(z = (197.5 - 200)/1 = -2.5\).

④ p-값 (양측): \(2 \cdot P(Z < -2.5) = 2 \times 0.0062 = 0.0124\) (1.24%).

⑤ 결론: \(0.0124 < 0.05\) → \(H_0\) 기각. 표시된 200g과 실제 평균이 다르다는 증거 충분.

정답

5% 유의수준에서 \(H_0\) 기각. 평균 무게가 200g이 아니라는 통계적 증거 있음. (관측값이 작으니 "표시보다 적음" 의심.)

임계값 비교법

5% 양측 임계값 \(z_{0.025} = 1.96\). \(|z| = 2.5 > 1.96\) → 같은 결론 (기각).

PROBLEM 08 · 한 비율 H.T. 단측

⑧ 신약 효능 — 단측 검정 ⭐

기존 치료율 대비 신약이 더 좋은가?
문제

기존 치료법의 완치율은 70%로 알려져 있다. 신약을 \(n = 200\)명에게 투여한 결과 152명이 완치되었다.

신약이 기존 치료법보다 더 효과적이라는 증거가 \(\alpha = 5\%\)에서 충분한가?

풀이

① 가설: \(H_0 : p \le 0.70, \quad H_1 : p > 0.70\) (오른쪽 단측).

② 표본 통계량: \(\hat{p} = 152/200 = 0.76\).

③ SE (H₀ 하 — 경계값 \(p = 0.70\) 사용): \(\sqrt{0.70 \times 0.30 / 200} = \sqrt{0.00105} = 0.0324\).

④ z-통계량: \(z = (0.76 - 0.70)/0.0324 = 1.85\).

⑤ p-값 (단측): \(P(Z > 1.85) = 1 - 0.9678 = 0.0322\) (3.22%).

⑥ 결론: \(0.0322 < 0.05\) → \(H_0\) 기각. 신약이 더 효과적이라는 증거 충분.

정답

5% 유의수준에서 \(H_0\) 기각. 신약의 완치율이 기존 70%보다 통계적으로 더 높다고 결론.

⚠️ 단측 vs 양측

같은 데이터라도 양측에서는 p-값이 \(0.0322 \times 2 = 0.0644 > 0.05\) → 기각 불가. 단측을 쓰려면 방향이 사전에 정해져 있어야 함 — "기존보다 좋다" 같은 명확한 가설.

PROBLEM 09 · 두 평균 H.T.

⑨ A/B 광고 노출 비교 ⭐

독립 표본 — μ_A vs μ_B
문제

두 광고 A, B의 클릭 후 페이지 체류시간(초)을 비교. 각각 \(n_A = n_B = 200\)명 무작위 노출.

광고 A: \(\bar{X}_A = 45\), \(\sigma_A = 12\). 광고 B: \(\bar{X}_B = 41\), \(\sigma_B = 15\).

두 광고의 평균 체류시간이 다른지 \(\alpha = 1\%\)에서 검정하시오.

풀이

① 가설: \(H_0 : \mu_A - \mu_B = 0, \quad H_1 : \mu_A - \mu_B \ne 0\) (양측).

② 표본 평균 차: \(\bar{X}_A - \bar{X}_B = 45 - 41 = 4\).

③ SE (독립 표본):

\[ \text{SE} = \sqrt{\frac{\sigma_A^2}{n_A} + \frac{\sigma_B^2}{n_B}} = \sqrt{\frac{12^2}{200} + \frac{15^2}{200}} = \sqrt{0.72 + 1.125} = \sqrt{1.845} = 1.358 \]

④ z-통계량: \(z = 4 / 1.358 = 2.95\).

⑤ p-값 (양측): \(2 \cdot P(Z > 2.95) = 2 \times 0.0016 = 0.0032\) (0.32%).

⑥ 결론: \(0.0032 < 0.01\) → \(H_0\) 기각. 두 광고의 평균 체류시간이 다르다는 강한 증거.

정답

1% 유의수준에서 기각. 광고 A의 체류시간이 광고 B보다 통계적으로 더 길다고 결론 가능 (\(\bar{X}_A > \bar{X}_B\)이므로 방향까지).

두 평균 SE 공식

독립 표본: \(\sqrt{\sigma_A^2/n_A + \sigma_B^2/n_B}\). 두 분산을 표본크기로 나눠 더한 뒤 제곱근.

PROBLEM 10 · 짝지은 표본

⑩ 다이어트 전후 비교 ✏️

Paired sample — D = X - Y
문제

다이어트 프로그램 효과 검증. 같은 \(n = 50\)명을 대상으로 시작 시점과 8주 후 체중 측정.

시작: \(\bar{X}_1 = 72.5\)kg. 8주 후: \(\bar{X}_2 = 70.8\)kg. 차이 \(D = X_1 - X_2\)의 표본 표준편차 \(S_D = 3.2\)kg.

다이어트 효과가 있다는 (체중이 감소했다는) 증거가 \(\alpha = 5\%\)에서 충분한가?

풀이 — 짝 표본의 특수성

왜 독립 공식 못 씀?

같은 사람의 시작·종료 체중은 강한 양의 상관관계. 독립이라 가정하면 SE를 과대평가하게 됨. 해결: 차이 \(D\)를 새 변수로 만들어 한 표본 문제로 환원.

① 가설: \(H_0 : \mu_D = 0, \quad H_1 : \mu_D > 0\) (오른쪽 단측 — "체중 감소" 방향).

② \(\bar{D}\) 계산: \(\bar{D} = 72.5 - 70.8 = 1.7\)kg.

③ SE: \(\text{SE}_{\bar{D}} = S_D/\sqrt{n} = 3.2/\sqrt{50} = 3.2/7.07 = 0.453\).

④ z-통계량: \(z = 1.7 / 0.453 = 3.76\).

⑤ p-값 (단측): \(P(Z > 3.76) \approx 0.00008\) (0.008%) — 매우 작음.

⑥ 결론: p-값 \(\ll 0.05\) → \(H_0\) 강하게 기각. 다이어트 효과 있음 (체중 감소).

정답

5% (사실 1% 이하 어떤 수준에서도) 유의수준에서 기각. 8주간 평균 1.7kg 감량이 통계적으로 유의함.

핵심 패턴

"같은 사람을 두 번 측정" → 짝 표본. 차이 \(D = X_1 - X_2\)를 만들어 한 표본 검정. SE에는 \(S_D / \sqrt{n}\) (개별 \(S_X, S_Y\)는 못 씀).

PROBLEM 11 · 단순회귀 해석

⑪ 아파트 가격 vs 평수 🔥

β₁, R², 예측
문제

서울 아파트 100채 데이터로 단순회귀 추정 결과:

\[ \hat{\text{Price}} = 2.5 + 0.85 \cdot \text{Area} \quad (\text{Price: 억원, Area: 평}) \]

표준오차 \(\text{SE}(\hat{\beta}_1) = 0.12\), \(R^2 = 0.72\).

(a) \(\hat{\beta}_1 = 0.85\)의 비즈니스 의미는?

(b) "평수는 가격에 영향이 없다(\(\beta_1 = 0\))"를 \(\alpha = 5\%\)에서 검정.

(c) \(R^2 = 0.72\)의 의미는?

(d) 40평 아파트의 예상 가격은?

풀이

(a) 평수가 1평 늘 때 가격이 평균 0.85억(8,500만원) 오른다는 의미. 다른 모든 조건 동일.

(b) \(H_0 : \beta_1 = 0, \quad H_1 : \beta_1 \ne 0\).

\[ t\text{-stat} = \frac{\hat{\beta}_1 - 0}{\text{SE}(\hat{\beta}_1)} = \frac{0.85}{0.12} = 7.08 \]

큰 표본 (\(n = 100\))이므로 t ≈ Z. \(|z| = 7.08 \gg 1.96\) → \(H_0\) 강하게 기각. 평수는 가격에 통계적으로 유의한 영향 있음.

(c) \(R^2 = 0.72\) → "가격의 변동 중 72%를 평수가 설명함." 매우 강한 설명력.

(d) Area = 40 → \(\hat{\text{Price}} = 2.5 + 0.85 \times 40 = 2.5 + 34 = \mathbf{36.5}\)억원.

정답

(a) 1평당 +0.85억 / (b) 기각 (z=7.08) — 평수 영향 유의함 / (c) 가격 변동의 72% 설명 / (d) 36.5억원

회귀 해석 3박자

① 부호 (예상대로?) ② 크기 (실무 의미 있는?) ③ 유의성 (t-stat or p-value < 0.05?). 셋 다 통과해야 의사결정에 활용.

PROBLEM 12 · 다중회귀 + 더미

⑫ 매출 회귀 — 가격·프로모션·요일 ⭐

연속변수 + 더미변수 해석
문제

편의점 1년 매출 데이터로 회귀 추정:

\[ \hat{\text{Sales}} = 50 - 1.2 \cdot \text{Price} + 8.5 \cdot \text{Promo} + 12.3 \cdot \text{Weekend} \]

Promo = 1 (프로모션 진행), 0 (없음). Weekend = 1 (토·일), 0 (평일). \(n = 365\), \(R^2 = 0.58\), Adjusted \(R^2 = 0.57\).

모든 계수의 t-stat은 절댓값 3 이상.

(a) 각 계수의 비즈니스 의미를 한 줄씩.

(b) 프로모션 진행 + 주말일 때 (가격 5,000원 가정) 예상 매출은?

(c) Adjusted \(R^2\)와 \(R^2\)의 차이가 거의 없다. 이게 의미하는 것은?

풀이

(a) 각 계수 해석:

  • \(\beta_0 = 50\) — 모든 변수가 0일 때 (가격 0, 프로모션 없음, 평일) 매출 50. 실무 의미 적음 (절편).
  • \(\beta_1 = -1.2\) — 가격이 1원 오를 때 매출 평균 1.2 단위 감소. 부호 음수 — 합리적 (수요 법칙).
  • \(\beta_2 = +8.5\) — 프로모션을 진행하면 매출이 평균 +8.5 단위 증가 (가격·요일 통제 후).
  • \(\beta_3 = +12.3\) — 주말에는 매출이 평균 +12.3 단위 더 높음 (가격·프로모션 통제 후).

(b) 예측:

\[ \hat{\text{Sales}} = 50 - 1.2 \times 5{,}000 + 8.5 \times 1 + 12.3 \times 1 \]

주의 — 가격 단위에 따라 계수 해석이 다름. 위 식이 단위 정합하려면 Price를 천원 단위로 가정해야 합리적. Price = 5 (천원)로 가정:

\[ \hat{\text{Sales}} = 50 - 1.2 \times 5 + 8.5 + 12.3 = 50 - 6 + 8.5 + 12.3 = 64.8 \]

(c) Adjusted \(R^2\)와 \(R^2\)의 차이가 거의 없음 → 포함된 변수들이 모두 의미 있음 (불필요한 변수 추가가 없음). 변수마다 페널티가 작용했지만 거의 안 떨어졌으니 모두 기여한다는 신호.

정답

(a) 가격↑ 매출↓, 프로모션 +8.5, 주말 +12.3 / (b) 약 64.8 단위 / (c) 모든 변수가 모형에 기여하고 있음 (군더더기 없음)

더미변수의 의미

Promo·Weekend는 0/1 더미. 계수는 "그 조건이 켜졌을 때 추가되는 매출". 0이면 그 항 자체가 사라지므로 절편이 기본값이 됨. 더미는 카테고리 효과를 회귀에 넣는 표준 방법.
