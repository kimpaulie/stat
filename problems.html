CHAPTER 04 — Bayes Theorem

스마트폰 터치스크린이 누구 부품일까

베이즈 정리 — 결과를 보고 원인을 거꾸로 추론하기
문제 (배포용 PDF · Chapter 4)

ABC 전자의 스마트폰 모델 Z는 터치 스크린을 외부에서 공급받아요. 부품의 20%는 업체 X, 80%는 업체 Y에서 옵니다.

X 부품을 쓴 폰은 1년 후 80%가 고장 나고, Y 부품은 10%만 고장 나요.

당신이 1년 넘게 쓴 폰의 터치가 오늘 안 된다는 걸 알았다고 할 때, 그 부품은 X와 Y 중 어느 쪽일 가능성이 더 높을까요?

한 문장으로 본질 잡기

베이즈 정리는 한마디로 이래요. “겉으로 드러난 결과(메시지)를 보고, 숨어 있는 진짜 원인(진실)을 거꾸로 추론하는 방법.”

진실 vs 메시지
교수님이 강조하신 두 단어

진실(원인) — 실제로 어느 업체 부품이었는가. 우리는 모름.

메시지(결과) — 고장이 났다는 관찰. 우리는 이것만 알아요.

메시지 ⟶ 진실. 이게 바로 베이즈가 하는 일이에요.

문제가 준 방향 부품 \(X\) → 고장 \(U\)

\(P(U \mid X)\): \(X\) 부품이면 고장 날 확률

→
우리가 원하는 방향 고장 \(U\) → 부품 \(X\)?

\(P(X \mid U)\): 고장났다면 \(X\) 부품일 확률

1단계 · 기호부터 정리

이 문제의 기호
기호의미
\(X\)\(X\) 업체 부품을 사용함
\(Y\)\(Y\) 업체 부품을 사용함
\(U\)고장이 났다 (Unable to work)
\(P(X), P(Y)\)해당 부품을 쓸 사전 확률
\(P(U \mid X)\)\(X\) 부품일 때 고장 날 확률 — 주어진 값
\(P(X \mid U)\)고장 났을 때 \(X\) 부품일 확률 — 구할 값
방향이 반대!

문제는 \(P(U \mid X)\)를 줘요. ("\(X\)면 고장")
우리는 \(P(X \mid U)\)를 알고 싶어요. ("고장이면 \(X\)")
화살표가 거꾸로 돌아간 셈이라, 베이즈 공식이 필요한 거예요.

2단계 · 주어진 값 정리

\(P(X) = 0.20\)   ·   \(P(Y) = 0.80\)
\(P(U \mid X) = 0.80\)   ·   \(P(U \mid Y) = 0.10\)

3단계 · 교집합 \(P(U \cap X)\) 만들기

"\(X\) 부품인 동시에 고장도 난" 경우의 확률은 곱셈으로 풀려요.

\[ P(U \cap X) = P(X) \cdot P(U | X) = 0.20 \times 0.80 = \mathbf{0.16} \]

같은 식으로 \(Y\)쪽도 구하면:

\[ P(U \cap Y) = P(Y) \cdot P(U | Y) = 0.80 \times 0.10 = \mathbf{0.08} \]

4단계 · 전체 고장 확률 \(P(U)\)

고장 나는 길은 두 가지뿐이에요. 둘을 더하면 끝.

\[ P(U) = P(U \cap X) + P(U \cap Y) = 0.16 + 0.08 = \mathbf{0.24} \]

5단계 · 베이즈로 답 구하기

\[ P(X | U) = \frac{P(U \cap X)}{P(U)} = \frac{0.16}{0.24} \approx \mathbf{0.6667} \]

나머지 \(Y\)쪽도 계산해 보면:

\[ P(Y | U) = 0.08 / 0.24 \approx \mathbf{0.3333} \]
최종 결론

고장이 났다면 \(X\) 부품일 확률 \(\approx 66.7\%\), \(Y\) 부품일 확률 \(\approx 33.3\%\).

즉, \(X\) 업체 부품일 가능성이 더 높아요.

100대로 다시 보면 (직관 체크)

혹시 식이 어색하면 100대로 상상해 봐요.

전체 100대 시뮬레이션
구분대수고장률고장난 대수
\(X\) 부품20대80%16대
\(Y\) 부품80대10%8대
합계100대—24대 고장

고장난 24대 중 \(X\) 부품은 16대 → \(16/24 \approx\) 66.7%. 똑같죠!

여집합까지 보면 더 선명해져요

ques.md에서 정리한 것처럼, 이 문제는 고장났을 때뿐 아니라 고장나지 않았을 때를 같이 보면 베이즈 감각이 훨씬 좋아져요. 고장이 나지 않았다는 메시지는 X보다 Y 쪽으로 강하게 기울어지거든요.

\(X\)의 여집합

부품 업체가 \(X\)와 \(Y\)뿐이라면 \(X^c\)는 곧 \(Y\)예요.

\(P(X^c) = P(Y) = 0.80\)

\(U\)의 여집합

\(U\)가 고장이라면 \(U^c\)는 고장나지 않음이에요.

\(P(U^c \mid X) = 0.20\), \(P(U^c \mid Y) = 0.90\)

\[ P(X | U^c) = \frac{0.20 \times 0.20}{0.20 \times 0.20 + 0.80 \times 0.90} = \frac{0.04}{0.76} \approx \mathbf{0.0526} \]
반대 메시지의 힘

고장났다면 \(X\)일 확률은 약 66.7%였지만, 고장나지 않았다면 \(X\)일 확률은 약 5.26%까지 내려가요. 같은 부품 정보라도 관찰한 메시지가 바뀌면 결론이 완전히 달라지는 게 베이즈의 핵심입니다.

코로나 검사 키트와 똑같아요.

"검사 결과가 양성"이라는 메시지를 보고, 진짜 감염 여부를 추론하는 일이 베이즈예요. 양성이라고 해서 무조건 감염은 아니지만, 양성일 때 감염일 확률이 얼마인지를 계산할 수 있어요.

시험 답안 깔끔하게

\(X\) = \(X\) 부품 사용 사건, \(U\) = 고장 사건이라 하자. 주어진 값:

\(P(X) = 0.2\), \(P(Y) = 0.8\), \(P(U \mid X) = 0.8\), \(P(U \mid Y) = 0.1\)

베이즈 정리에 의해

\(P(X \mid U) = P(U \cap X) / P(U)\)
    \(= P(X)P(U \mid X) / [P(X)P(U \mid X) + P(Y)P(U \mid Y)]\)
    \(= (0.2 \cdot 0.8) / (0.2 \cdot 0.8 + 0.8 \cdot 0.1)\)
    \(= 0.16 / 0.24 \approx 0.667\)

따라서 \(X\) 부품일 확률(\(\approx 66.7\%\))이 \(Y\) 부품일 확률(\(\approx 33.3\%\))보다 크다.

KEY TAKEAWAY
베이즈 = "결과(메시지) → 원인(진실)"의 거꾸로 추론. 분자엔 \(P(\)원인\() \cdot P(\)결과\(|\)원인\()\), 분모엔 모든 원인의 합.
CHAPTER 05a — Joint Distribution

코로나와 삿포로는 독립일까

결합분포 · 독립의 두 가지 판정법
문제 (배포용 PDF · Chapter 5a)

한 상점이 코로나 맥주(\(X\))와 삿포로 맥주(\(Y\))를 팝니다. 두 수요의 결합분포가 아래 표예요.

결합분포표 (행=삿포로 \(Y\), 열=코로나 \(X\))
\(Y \setminus X\)0123\(P(Y)\)
00.010.030.060.090.19
10.020.060.120.090.29
20.030.120.060.090.30
30.040.090.060.030.22
\(P(X)\)0.100.300.300.301.00
표를 읽는 법

표 안쪽 숫자는 두 일이 동시에 일어날 확률이에요. 예를 들어 \(P(X=1, Y=3) = 0.09\)는 “코로나 1개, 삿포로 3개가 같이 팔릴 확률이 9%”라는 뜻입니다.

표의 아래쪽 \(P(X)\)는 코로나만 따로 본 확률, 오른쪽 \(P(Y)\)는 삿포로만 따로 본 확률이에요. 그래서 이름이 주변확률입니다. 표의 가장자리, 즉 주변에 있죠.

독립이란?

독립 · Independent
한쪽 정보가 다른 쪽 확률을 바꾸지 않는 관계

"코로나가 1개 팔렸다는 사실을 알아도, 삿포로가 3개 팔릴 확률이 그대로면" 독립. 반대로 그 확률이 바뀌면 독립이 아니에요.

판정법 ① — 조건부 확률 방식

독립이라면 다음이 성립해야 해요.

\[ P(Y = y | X = x) = P(Y = y) \quad \text{(모든 } x, y \text{에 대해)} \]

교수님이 칠판에서 직접 확인하신 값: \(P(Y=3 \mid X=1)\).

\(P(X=1, Y=3) = 0.09\)   ·   \(P(X=1) = 0.30\)
\[ P(Y=3 | X=1) = 0.09 / 0.30 = \mathbf{0.30} \]

그런데 주변확률은 \(P(Y=3) =\) 0.22예요. 두 값이 다르죠?

결론 ①

\(0.30 \ne 0.22\) 이므로 \(P(Y=3 \mid X=1) \ne P(Y=3)\).
\(X\)와 \(Y\)는 독립이 아니에요.

판정법 ② — 곱셈 공식 방식

독립이면 또 다른 방식으로도 확인할 수 있어요.

\[ P(X = x, Y = y) = P(X = x) \cdot P(Y = y) \]

교수님이 보신 칸: \(X = 2, Y = 2\).

실제값: \(P(X=2, Y=2) = 0.06\)
독립이면: \(P(X=2) \times P(Y=2) = 0.30 \times 0.30 = 0.09\)
결론 ②

\(0.06 \ne 0.09\) 이므로 곱셈 공식 위배.
역시 독립이 아니에요.

두 판정법은 사실 같은 말

조건부 확률 정의:

\[ P(Y | X) = \frac{P(X \cap Y)}{P(X)} \]

독립이면 \(P(Y \mid X) = P(Y)\) 이므로 양변에 \(P(X)\)를 곱하면 \(P(X \cap Y) = P(X)P(Y)\). 두 식이 자연스럽게 변환돼요.

"모두가 숙제를 했다"의 반례.

"전원이 했다"를 부정하려면 안 한 사람 한 명만 찾으면 끝이죠. 독립도 그래요. 16개 칸 중 한 칸만 어긋나도 "독립이 아님" 결론이 가능해요.

시험 답안 (방법 1)

\(X\) = 코로나 수요, \(Y\) = 삿포로 수요로 두자.
독립이면 \(P(Y=3 \mid X=1) = P(Y=3)\)이어야 한다.
\(P(X=1, Y=3) = 0.09\), \(P(X=1) = 0.30\) 이므로
\(P(Y=3 \mid X=1) = 0.09/0.30 = 0.30\).
반면 \(P(Y=3) = 0.22\).
\(\therefore 0.30 \ne 0.22\)이므로 \(X, Y\)는 독립이 아니다.

KEY TAKEAWAY
독립 판정 = "한 칸이라도 \(P(x,y) \ne P(x)P(y)\)면 끝." 가장 의심스러운 칸 한 개 골라 확인하면 충분.
CHAPTER 05b

두 맥주의 평균과 분산

\(E[X], \mathrm{Var}[X], E[Y], \mathrm{Var}[Y]\) 한 번에
문제

코로나(\(X\))와 삿포로(\(Y\)) 수요 각각의 평균과 분산을 구하시오.

주변확률만 있으면 끝

코로나 \(X\)
표 아래쪽 주변

\(P(X=0) = 0.10\), \(P(X=1) = 0.30\),
\(P(X=2) = 0.30\), \(P(X=3) = 0.30\)

삿포로 \(Y\)
표 오른쪽 주변

\(P(Y=0) = 0.19\), \(P(Y=1) = 0.29\),
\(P(Y=2) = 0.30\), \(P(Y=3) = 0.22\)

평균 \(E[X], E[Y]\)

\[ E[X] = 0(0.10) + 1(0.30) + 2(0.30) + 3(0.30) = \mathbf{1.80} \]
\[ E[Y] = 0(0.19) + 1(0.29) + 2(0.30) + 3(0.22) = \mathbf{1.55} \]

분산 — 두 가지 방법

교수님이 두 가지 방식을 모두 보여주셨어요.

방법 ① 정의식

\(\mathrm{Var}[X] = E[(X - E[X])^2]\)
→ 분산의 의미가 잘 보이는 식이에요. "평균에서 떨어진 거리의 제곱의 평균."

방법 ② 빠른 공식

\(\mathrm{Var}[X] = E[X^2] - (E[X])^2\)
→ 계산이 빨라서 시험에서는 보통 이 식을 써요.

대괄호 표기 겁먹지 않기

\(E[X]\)는 “\(X\)의 평균을 구하라”, \(\mathrm{Var}[X]\)는 “\(X\)의 분산을 구하라”는 뜻이에요. \(E[Y^2]\)는 “\(Y\)를 먼저 제곱한 뒤, 그 값들의 평균을 구하라”는 뜻입니다.

즉 대괄호는 새로운 마법 기호가 아니라, 무엇의 평균/분산을 구하는지 감싸 보여주는 표시예요.

코로나 \(X\) 분산 (방법 ②)

\[ E[X^2] = 0^2(0.10) + 1^2(0.30) + 2^2(0.30) + 3^2(0.30) = \mathbf{4.20} \]
\[ Var[X] = E[X^2] - (E[X])^2 = 4.20 - (1.80)^2 = 4.20 - 3.24 = \mathbf{0.96} \]

정의식으로도 한 번 느껴보기 (\(X\))

계산은 빠른 공식이 편하지만, 분산의 뜻은 정의식에서 더 잘 보여요. \(X\)의 평균 1.80에서 각 값이 얼마나 떨어져 있는지 제곱해서 확률로 가중평균합니다.

\((0-1.80)^2 \times 0.10 = 0.324\)
\((1-1.80)^2 \times 0.30 = 0.192\)
\((2-1.80)^2 \times 0.30 = 0.012\)
\((3-1.80)^2 \times 0.30 = 0.432\)
합계 = 0.96

CHAPTER 05c

공분산과 상관계수

두 수요가 같이 움직이는가, 반대로 움직이는가
문제

코로나와 삿포로 수요 사이의 공분산과 상관계수는?

공분산이 뭐였더라

Covariance · 공분산
두 변수가 같은 방향으로 움직이는 정도

+면 같이 오르고 같이 내림. −면 반대로 움직임. 0 근처면 직선적 관계가 약함.

두 가지 공식

① 정의식

\(\mathrm{Cov}[X,Y] = E[(X - E[X])(Y - E[Y])]\)

② 빠른 공식

\(\mathrm{Cov}[X,Y] = E[XY] - E[X] \cdot E[Y]\)

\(E[XY]\) 계산하기

16칸을 일일이 계산해서 더해요. 다행히 \(Y=0\) 행은 모두 0이라 빼고 시작.

왜 \(x \cdot y \cdot P(x,y)\)를 더할까?

\(E[X]\)가 \(x\)값에 \(P(X=x)\)를 곱해 더하는 것처럼, \(E[XY]\)는 두 수요를 곱한 값 \(xy\)에 그 조합이 나올 확률 \(P(x,y)\)를 곱해 더합니다.

예를 들어 \(X=2, Y=3\)이면 그날 두 수요의 곱은 6이고, 이 조합의 확률은 0.09라서 \(E[XY]\)에 \(6 \times 0.09\)만큼 기여해요.

\(Y=1\) 행: \(0 \cdot 1 \cdot 0.02 + 1 \cdot 1 \cdot 0.06 + 2 \cdot 1 \cdot 0.12 + 3 \cdot 1 \cdot 0.09 = 0 + 0.06 + 0.24 + 0.27 = 0.57\)
\(Y=2\) 행: \(0 + 0.24 + 0.24 + 0.54 = 1.02\)
\(Y=3\) 행: \(0 + 0.27 + 0.36 + 0.27 = 0.90\)
\(E[XY] = 0 + 0.57 + 1.02 + 0.90 = 2.49\)

공분산 계산

\[ Cov[X,Y] = E[XY] - E[X]E[Y] = 2.49 - (1.80 \times 1.55) = 2.49 - 2.79 = \mathbf{-0.30} \]
해석

공분산이 음수예요. 코로나가 많이 팔릴 때 삿포로는 조금 덜 팔리는 경향. (재미있게 비유하자면, "한 사람당 맥주 예산은 한정돼 있어서 한쪽이 많아지면 다른 쪽이 줄어드는" 그림.)

상관계수 \(\rho\)

공분산은 단위에 따라 크기가 들쭉날쭉해서, 단위 영향을 없앤 표준화 버전이 상관계수예요.

\[ \rho = \frac{Cov[X, Y]}{\sigma_X \cdot \sigma_Y} \]
\(\sigma_X = \sqrt{0.96} \approx 0.9798\)
\(\sigma_Y = \sqrt{1.0675} \approx 1.0332\)
분모 \(= 0.9798 \times 1.0332 \approx 1.0124\)
\[ \rho = -0.30 / 1.0124 \approx \mathbf{-0.296} \]

해석

상관계수 읽는 법
\(\rho\)해석
+1에 가까움강한 양의 직선 관계
0 근처관계가 약함
우리 결과 \(\approx -0.30\)약한 음의 관계
\(-1\)에 가까움강한 음의 직선 관계

그러니까 "살짝 반대로 움직이는 두 맥주"라고 보면 돼요. 강하진 않아요.

시험 답안

\(E[XY] = \sum\sum xy P(x,y) = 2.49\)
\(\mathrm{Cov}[X,Y] = E[XY] - E[X]E[Y] = 2.49 - (1.80)(1.55) = -0.30\)
\(\sigma_X = \sqrt{0.96} , \sigma_Y = \sqrt{1.0675}\)
\(\rho = \mathrm{Cov}[X,Y] / (\sigma_X \sigma_Y) = -0.30 / (\sqrt{0.96} \cdot \sqrt{1.0675}) \approx\) \(-0.296\)

KEY TAKEAWAY
\(\mathrm{Cov}\)는 방향, \(\rho\)는 단위 없는 강도. 두 식을 함께 외우면 만점.
CHAPTER 05d

총 수요 \(X+Y\)의 평균과 분산

앞 결과를 활용해서 한 줄로 끝내기
문제

코로나와 삿포로의 총 수요 \(X + Y\)의 평균과 분산은?

평균은 그냥 더하기

\[ E[X + Y] = E[X] + E[Y] = 1.80 + 1.55 = \mathbf{3.35} \]

평균은 독립이든 아니든 항상 더하기 OK예요. "기댓값의 선형성"이라고 부르는 성질이죠.

분산은 공분산을 잊지 마세요

분산은 단순히 더하면 안 돼요. 공분산이 살아 있거든요.

\[ Var[X + Y] = Var[X] + Var[Y] + 2 \cdot Cov[X, Y] \]
자주 하는 실수

독립이라면 \(\mathrm{Cov} = 0\)이어서 단순 합 OK. 하지만 이번엔 \(\mathrm{Cov} = -0.30\)이라 0이 아니에요.

숫자 대입

\[ Var[X + Y] = 0.96 + 1.0675 + 2 \times (-0.30) \]
\[ = 2.0275 - 0.60 = \mathbf{1.4275} \]
왜 분산이 줄었지?

공분산이 음수라서요. 한쪽이 많으면 다른 쪽이 적은 상쇄 효과가 생겨서, "총합"은 둘을 따로 본 것보다 덜 흔들려요.

최종 답

5d 결과
항목값
총 수요 평균 \(E[X+Y]\)3.35
총 수요 분산 \(\mathrm{Var}[X+Y]\)1.4275
시험 답안

\(E[X+Y] = E[X] + E[Y] = 1.80 + 1.55 =\) 3.35

\(\mathrm{Var}[X+Y] = \mathrm{Var}[X] + \mathrm{Var}[Y] + 2\,\mathrm{Cov}[X,Y]\)
  \(= 0.96 + 1.0675 + 2(-0.30)\)
  \(=\) 1.4275

KEY TAKEAWAY
평균은 더하기, 분산은 공분산까지. 음의 공분산은 총 분산을 줄여줘요.

CHAPTER 06 · Q3

"A 학생 지출이 B의 2배 이상일 확률"

D = X − 2Y 변환의 트릭
문제

A 지역 학생 일일 지출 X ~ N(9000, 1500²), B 지역 학생 일일 지출 Y ~ N(8000, 2500²). 두 학생은 독립.

P(X \(\ge\) 2Y) = ?

식 다시 쓰기

"X \(\ge\) 2Y"는 양변에서 2Y를 빼면 X − 2Y \(\ge\) 0. 새 변수 D를 만들어요.

\[ D = X - 2Y \quad \Rightarrow \quad P(X \ge 2Y) = P(D \ge 0) \]

정규분포의 선형결합도 정규분포라는 사실이 결정적이에요. 그래서 D 자체가 정규분포를 따른다는 보장이 있어요.

왜 굳이 D를 만들까?

X와 Y를 따로 보면 “A가 B의 2배 이상”이라는 문장이 계속 불편해요. D = X − 2Y라고 이름을 붙이면 문제는 딱 하나로 줄어요.

D가 0보다 크면 성공, 0보다 작으면 실패. 이제는 평범한 정규분포 꼬리 확률 문제가 됩니다.

D의 평균

\[ E[D] = E[X] - 2E[Y] = 9000 - 2(8000) = \mathbf{-7000} \]

평균이 음수라는 건, "보통은 X가 2Y에 못 미친다"는 사실을 의미해요. 그럼에도 흔들림으로 0 위로 갈 확률을 묻는 거죠.

D의 분산 (독립이라 깔끔)

중요한 두 규칙.

① 상수 곱

Var[aY] = a² Var[Y]
→ Var[2Y] = 4 Var[Y]

② 독립이면 합

Var[X − 2Y] = Var[X] + Var[2Y]
→ 부호가 −여도 분산은 더해요.

\[ Var[D] = 1500^2 + 4(2500^2) = 2{,}250{,}000 + 25{,}000{,}000 = \mathbf{27{,}250{,}000} \]
\[ \sigma_D = \sqrt{27{,}250{,}000} \approx \mathbf{5{,}220} \]

표준화 후 표 찾기

\[ z = (0 - (-7000)) / 5220 \approx \mathbf{1.34} \]
\[ P(D \ge 0) = P(Z \ge 1.34) = 1 - P(Z < 1.34) = 1 - 0.9099 = \mathbf{0.0901} \]
최종 답

P(X \(\ge\) 2Y) \(\approx\) 0.0901 \(\approx\) 약 9%

A 평균(9,000)은 B 평균의 2배(16,000)보다 한참 작으니, 2배 넘기는 일은 흔치 않아요.

시험 답안

D = X − 2Y로 두면 P(X \(\ge\) 2Y) = P(D \(\ge\) 0).
E[D] = 9000 − 2(8000) = −7000.
독립이므로 Var[D] = Var[X] + 4Var[Y] = 1500² + 4(2500²) = 27,250,000.
\(\sigma_{D} \approx\) 5220.
z = (0 − (−7000))/5220 \(\approx\) 1.34.
P(D \(\ge\) 0) = P(Z \(\ge\) 1.34) = 1 − 0.9099 \(\approx\) 0.0901.

KEY TAKEAWAY
두 정규변수의 비교 → 새 변수 D 만들고 P(D \(\ge\) 0) 또는 P(D \(\le\) 0). 독립이면 분산은 가법, 상수 곱은 제곱.
CHAPTER 06 · Q4

합집합 확률 P(X \(\ge\) 9000 \(\cup\) Y < 8000)

정규분포 + 또는(\(\cup\)) 공식
문제 (Q3 변수 그대로)

X ~ N(9000, 1500²), Y ~ N(8000, 2500²), 독립.
P(X \(\ge\) 9000 \(\cup\) Y < 8000) = ?

"또는" 공식 ①

\[ P(A \cup B) = P(A) + P(B) - P(A \cap B) \]

왜 빼냐고요? A와 B가 동시에 일어난 부분이 두 번 더해졌기 때문에 한 번 빼주는 거예요.

A X \(\ge\) 9000

A 학생 지출이 평균 이상

또는
B Y < 8000

B 학생 지출이 평균 미만

각 사건의 확률

A = {X \(\ge\) 9000}

X의 평균이 정확히 9000 → 정규분포 좌우 대칭
→ P(A) = 0.5

B = {Y < 8000}

Y의 평균이 정확히 8000 → 좌우 대칭
→ P(B) = 0.5

왜 0.5?

경계값이 그 변수의 평균이라서요. 평균을 기준으로 좌우 면적이 정확히 50:50.

교집합 (독립 ⇒ 곱)

\[ P(A \cap B) = P(A) \cdot P(B) = 0.5 \times 0.5 = \mathbf{0.25} \]

합집합 계산

\[ P(A \cup B) = 0.5 + 0.5 - 0.25 = \mathbf{0.75} \]
최종 답

P(X \(\ge\) 9000 \(\cup\) Y < 8000) = 0.75 = 75%

1 − P(둘 다 아닌 경우)로도 풀 수 있어요.

둘 다 안 일어난 사건 = (X < 9000 \(\cap\) Y \(\ge\) 8000), 그 확률 = 0.5 × 0.5 = 0.25.
그래서 P(A \(\cup\) B) = 1 − 0.25 = 0.75. 같은 답!

시험 답안

A = {X \(\ge\) 9000}, B = {Y < 8000}. P(A) = P(B) = 0.5 (평균 기준 대칭).
독립이므로 P(A \(\cap\) B) = 0.5 × 0.5 = 0.25.
P(A \(\cup\) B) = P(A) + P(B) − P(A \(\cap\) B) = 0.5 + 0.5 − 0.25 = 0.75.

KEY TAKEAWAY
\(\cup\)는 단순 더하기 아님. 교집합 한 번 빼야. 평균이 경계면 0.5 즉시 사용.
CHAPTER 07 · Q1 — Sampling and CLT

표본평균의 분포

\(\mu\) = 100, \(\sigma\) = 20, n = 100인 경우
문제

\(X_{1}\), …, \(X_{100}\)이 \(\mu\)=100, \(\sigma\)=20인 모집단에서 무작위 추출. \(\bar{X}\)가 표본평균.

(a) \(\bar{X}\)의 기대값과 표준편차
(b) 표준오차는?
(c) P(\(\bar{X}\) < 95)와 P(95 < \(\bar{X}\) < 105)

표본평균의 두 핵심 공식

E[\(\bar{X}\)] = \(\mu\)

표본평균의 평균은 모평균과 같다. 편향 없음.

SD[\(\bar{X}\)] = \(\sigma\)/\(\sqrt{n}\)

표본 크기 n이 커지면 흔들림이 \(\sqrt{n}\) 비율로 줄어요.

\(\bar{X}\)도 확률변수예요

한 번 100개를 뽑아 평균을 내면 \(\bar{X}\)가 하나 나옵니다. 그런데 표본을 다시 뽑으면 평균이 98일 수도, 102일 수도 있어요.

그래서 \(\bar{X}\)는 고정된 숫자가 아니라 표본을 뽑을 때마다 달라지는 평균이고, 그 평균들이 어떤 분포로 흩어지는지를 보는 게 7장의 핵심입니다.

(a) 답

E[\(\bar{X}\)] = \(\mu\) = 100
SD[\(\bar{X}\)] = \(\sigma\)/\(\sqrt{n}\) = 20/\(\sqrt{100}\) = 20/10 = 2
Var[\(\bar{X}\)] = (20)²/100 = 4
왜 표준편차가 20에서 2로 줄었지?

한 사람의 키는 들쭉날쭉하지만, 100명 평균의 키는 안정적이에요. "여러 명의 평균은 덜 흔들린다"는 자연스러운 직관.

(b) 표준오차

표준오차(Standard Error, SE)는 표본평균의 표준편차예요. (a)에서 이미 구했어요.

\[ SE = \sigma/\sqrt{n} = \mathbf{2} \]
표준편차와 표준오차의 차이
이름의미이 문제 값
표준편차 \(\sigma\)개별 X의 흔들림20
표준오차 SE표본평균 \(\bar{X}\)의 흔들림2

(c) 두 확률 계산

n = 100이라 CLT 적용. \(\bar{X} \approx\) N(100, 2²). 표준화하면 Z = (\(\bar{X}\) − 100)/2.

① P(\(\bar{X}\) < 95)

\[ z = (95 - 100)/2 = \mathbf{-2.5} \]
\[ P(\bar{X} < 95) = P(Z < -2.5) \approx \mathbf{0.0062} \]

② P(95 < \(\bar{X}\) < 105)

\[ z_1 = -2.5, \quad z_2 = 2.5 \]
\[ P(-2.5 < Z < 2.5) = 0.9938 - 0.0062 = \mathbf{0.9876} \]
최종 답

(a) E[\(\bar{X}\)] = 100, SD[\(\bar{X}\)] = 2
(b) SE = 2
(c) P(\(\bar{X}\) < 95) \(\approx\) 0.62%,   P(95 < \(\bar{X}\) < 105) \(\approx\) 98.76%

해석. 모평균이 100인 세상에서, 100명 평균이 95~105 안에 들어올 확률이 무려 98.76%. 반대로 95 미만으로 떨어질 확률은 1%도 안 돼요. "표본이 모평균을 정말 잘 대표한다"는 신호예요.

KEY TAKEAWAY
E[\(\bar{X}\)] = \(\mu\), SD[\(\bar{X}\)] = \(\sigma\)/\(\sqrt{n}\). n이 커지면 \(\sqrt{n}\)으로 폭이 좁아지는 게 핵심.
CHAPTER 07 · Q2

표본비율 \(\bar{p}\) — 같은 n인데 왜 표준오차가 다를까

교수님이 시험에 잘 낸다고 강조하신 그 문제
문제

k-shop.com 방문 → 구매 확률 p. 100회 방문에서 구매 비율을 \(\bar{p}\)라 하자.

(a) p = 0.45일 때 E[\(\bar{p}\)], SD[\(\bar{p}\)]
(b) p = 0.15일 때 E[\(\bar{p}\)], SD[\(\bar{p}\)]
(c) 같은 n인데 왜 표준오차가 다른가?

표본비율의 공식

p와 \(\bar{p}\) 구분하기
기호뜻예시
p진짜 구매 확률, 모비율실제 구매 확률 45%
\(\bar{p}\)100번 방문에서 관찰된 구매 비율100번 중 47번 구매 → 0.47
E[\(\bar{p}\)] = p

표본비율의 평균은 모비율과 같다.

SD[\(\bar{p}\)] = \(\sqrt{p(1-p)/n}\)

"베르누이의 분산 p(1−p)"를 n으로 나눠 √.

(a) p = 0.45, n = 100

\[ E[\bar{p}] = 0.45 \]
Var[\(\bar{p}\)] = 0.45 × 0.55 / 100 = 0.2475 / 100 = 0.002475
SD[\(\bar{p}\)] = \(\sqrt{0.002475} \approx\) 0.0497

(b) p = 0.15, n = 100

\[ E[\bar{p}] = 0.15 \]
Var[\(\bar{p}\)] = 0.15 × 0.85 / 100 = 0.1275 / 100 = 0.001275
SD[\(\bar{p}\)] = \(\sqrt{0.001275} \approx\) 0.0357

(c) 같은 n인데 왜 다르지?

식을 다시 보면 답이 보여요.

\[ SD[\bar{p}] = \sqrt{\frac{p(1-p)}{n}} \]

n은 같으니, 차이는 p(1−p)에서 옵니다.

교수님 강조 포인트

p(1−p)는 p = 0.5에서 최대.

즉 "p가 클수록 표준오차가 크다"가 아니라, "p가 0.5에 가까울수록 표준오차가 크다"가 정확한 표현.

동전 던지기 직관.

p = 0.5 (앞·뒤 반반) — 결과 예측이 가장 어렵다 → 흔들림 최대.
p = 0.9 (거의 앞면) — 결과가 거의 정해져 있다 → 흔들림 작음.
p = 0.1 (거의 뒷면) — 마찬가지로 흔들림 작음.

이 문제에서 0.45는 0.5에 매우 가깝고, 0.15는 멀어요. 그래서 (a)가 (b)보다 표준오차가 커요.

시험 답안 (c)

표본 크기 n이 같아도 표준오차는 \(\sqrt{p(1-p)/n}\)에서 p의 영향을 받는다. p(1−p)는 p = 0.5에서 최대이므로, p가 0.5에 가까울수록 표준오차가 커진다.

여기서 p = 0.45는 p = 0.15보다 0.5에 더 가까워, p(1−p)가 크다(0.2475 vs 0.1275). 따라서 (a)의 표준오차가 (b)보다 크다.

KEY TAKEAWAY
SD[\(\bar{p}\)] = \(\sqrt{p(1-p)/n}\). 분자의 p(1−p)는 0.5에서 최대. "p가 0.5에 가까울수록 더 흔들린다"는 한 문장이면 (c)는 만점.
